# khmer-converter

A web page and a Telegram bot for converting between romanized Khmer and Khmer script.

Paste `sok sabay` and get សុខសប្បាយ, or paste Khmer script and get romanized text back. The Telegram
bot also works inline: type `@botname sok sabay` in any chat to insert the Khmer result.

Only text you send as feedback ("wrong conversion") is stored. Nothing else you convert is kept.

## Status

Early development. Nothing to deploy yet.
